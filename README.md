# Fulton Calendar records

Private records for Fulton Calendar. The server on Render reads and writes these files. Nothing here needs editing by hand.

- `settings/program.json` holds the calendar names, the spaces and the hours shown.
- `settings/feeds.json` holds the addresses of the Google calendars. Keep it private, since anyone holding an address can read that calendar.
- `bookings` holds the space sign-ups, one file per month.
